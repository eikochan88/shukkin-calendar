# 出勤カレンダーメーカー

ナイトワーク従事者が、写真の上に月間出勤カレンダーを重ねた Instagram（4:5）用画像を作る Web アプリです。

## 開発

```bash
npm install
npm run dev -- --host
```

iPhone 実機確認: Mac と同じ Wi-Fi で表示されるネットワーク URL を Safari で開く。

## ビルド

```bash
npm run build
npm run preview
```

## デプロイ（Vercel）

このリポジトリを Vercel にインポートし、Framework Preset は Vite のままでデプロイしてください。
