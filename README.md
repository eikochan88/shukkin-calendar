# 出勤カレンダーメーカー

ナイトワーク従事者が、写真の上に月間出勤カレンダーを重ねた Instagram（4:5）用画像を作る Web アプリです。

## スマホで使う（公開 URL）

https://eikochan88.github.io/shukkin-calendar/

Safari で開いて、ホーム画面に追加するとアプリのように使えます。

## 開発

```bash
npm install
npm run dev -- --host
```

iPhone 実機確認: Mac と同じ Wi-Fi で表示されるネットワーク URL を Safari で開く。

## ビルド

```bash
npm run build
npm run preview
```

## デプロイ

`main` への push で GitHub Pages に自動デプロイされます。
